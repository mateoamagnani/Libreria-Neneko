🔧 Implementación Técnica

Skeleton Loader CSS

.product-thumb::before { content: ''; position: absolute; top: 0; left: 0; right: 0; bottom: 0; background: linear-gradient(90deg, var(--surface-2) 0%, color-mix(in srgb, var(--border) 50%, var(--surface-2)) 50%, var(--surface-2) 100%); background-size: 200% 100%; animation: skeleton-pulse 1.5s infinite; opacity: 0; transition: opacity .4s ease; } .product-thumb[data-loading="true"]::before { opacity: 1; } .product-thumb[data-loading="false"]::before { opacity: 0; } @keyframes skeleton-pulse { 0% { background-position: 200% 0; } 100% { background-position: -200% 0; } }

Image Loading & Fade-in

<img src="..." data-loading="true" onload="this.dataset.loading='false'" onerror="this.dataset.loading='false'" /> .product-thumb img { transition: opacity .4s ease; } .product-thumb img[data-loading="true"] { opacity: 0; } .product-thumb img[data-loading="false"] { opacity: 1; }

✗ Antes (Sin optimización)

• Imágenes cargan solo cuando entran en viewport
• Sin feedback visual durante carga
• Espacio en blanco mientras carga
• Parece roto o no responde

✓ Después (Con optimización)

• Primeras 8 tarjetas cargan inmediatamente
• Skeleton loader muestra que algo está pasando
• Transición suave al cargar imagen
• Parece profesional y rápido

📊 Estrategias de Optimización

  • Skeleton Loader: Animación pulsante mientras carga
  • Preloading: Primeras 8 tarjetas sin loading="lazy"
  • Lazy Loading: Resto de tarjetas carga bajo demanda
  • Anticipatory Loading: rootMargin 100px en IntersectionObserver
  • Smooth Transitions: Fade-in de 0.4s cuando carga imagen
  • State Tracking: data-loading attributes para CSS reactivo
